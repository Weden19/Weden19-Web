# Weden19-Web

Одностраничный сайт-визитка Weden19. Чистый HTML/CSS/JS, без сборки.

- `index.html` — разметка
- `styles.css` — стили (glassmorphism, анимированный градиентный фон)
- `script.js` — RU/EN, копирование Discord-ника, анимации
- `assets/favicon.svg` — монограмма

Тексты RU/EN правятся в `script.js` (объект `i18n`).

## Деплой (GitHub Pages)

Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.
